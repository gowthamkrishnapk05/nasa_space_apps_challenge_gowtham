# OrbitCare – Astronaut Health Monitoring System

OrbitCare is a web-based astronaut health monitoring prototype developed for the **NASA Space Apps Challenge 2026**.

It simulates real-time health telemetry for astronauts during long-duration space missions, helping monitor vital signs, radiation exposure, sleep patterns, and potential health risks.

### Features
- Monitoring of heart rate, blood oxygen (SpO₂), and body temperature.
- Radiation dose and exposure tracking.
- Interactive health charts.
- Warning and critical health alerts.
- Solar particle event simulation.
- Cabin CO₂ spike simulation.
- Multiple astronaut profiles and mission-day tracking.

### Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

### Note
This project uses simulated data for demonstration purposes. It is a prototype and is not intended for actual medical diagnosis or astronaut health monitoring.

**Developed for NASA Space Apps Challenge 2026.**
